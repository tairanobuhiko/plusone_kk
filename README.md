# Plus One株式会社 ホームページ

群馬県前橋市の建築・内装工事会社、Plus One株式会社のホームページです。

- 公開先: https://plusone-kk.vercel.app
- ページ: トップ（`/`）、会社概要（`/about`）、お問い合わせ（`/contact`）

## 手元のパソコンで表示する

はじめての人向けに、画面の操作を順番に書きます。

### 1. 準備（最初の 1 回だけ）

1. Node.js を入れます。https://nodejs.org/ja を開き、「LTS」と書かれたボタンを押してインストーラーを保存し、開いて「続ける」を押していきます。
2. 「ターミナル」を開きます（Mac の場合: 画面右上の虫めがねを押し、「ターミナル」と入力して Enter）。
3. このフォルダに移動します。ターミナルに `cd ` と入力し（最後に半角の空白）、このフォルダをターミナルの画面へドラッグして Enter を押します。
4. 次の命令を入力して Enter を押します。必要な部品が入ります（数分かかります）。

   ```
   npm install
   ```

### 2. 表示する

1. ターミナルで次の命令を入力して Enter を押します。

   ```
   npm run dev
   ```

2. `Local: http://localhost:3000` と表示されたら、ブラウザ（Chrome や Safari）を開き、アドレス欄に `http://localhost:3000` と入力して Enter を押します。
3. 終わるときは、ターミナルの画面で `control` キーを押しながら `C` を押します。

問い合わせフォームのメール送信を手元で試すには、送信用の設定（`.env.local` というファイルに `ENV_GMAIL`、`ENV_GMAIL_PW`、`ENV_TO_MAIL` を書く）が要ります。設定が無くても、ページの表示は確認できます。

## 施工事例の写真を載せる

トップページの「施工事例」のブロックと、メニューの「施工事例」は、写真つきの事例が 1 件も無い間は表示されません。写真を 1 枚でも登録すると、どちらも自動で表示されます。写真が用意できたら、次の順で登録します。

### 1. 写真を置く

1. 写真のファイル名を、半角の英数字に変えます（例: `kitchen.jpg`）。日本語や空白は使いません。
2. Finder でこのフォルダを開き、`public` → `works` の順にフォルダを開きます。
3. 写真を `works` フォルダの中へドラッグして入れます。

写真は横長（横 4：縦 3 くらい）で、横幅 1200 ピクセルほどのものが向いています。縦長の写真は上下が切れて表示されます。

### 2. 一覧に書く

1. `data` フォルダの中の `works.ts` を、テキストエディット（または VS Code）で開きます。
2. 次のような行が 3 つ並んでいます。

   ```ts
   { title: "住宅内装リフォーム", text: "", image: "" },
   ```

3. 差し替えたい行を、次のように書き換えます。

   ```ts
   { title: "キッチンの入れ替え", text: "前橋市 / 2026年", image: "kitchen.jpg" },
   ```

   | 項目 | 書く内容 |
   |---|---|
   | `title` | 事例の題名 |
   | `text` | 短い説明。要らなければ `""` のままにします |
   | `image` | 手順 1 で置いた写真のファイル名。`""` のままの事例は表示されません |

4. 事例を増やすときは、行をまるごとコピーして下に貼り付け、中身を書き換えます。減らすときは、行をまるごと消します。
5. 保存します（`command` キーを押しながら `S`）。

`"` （半角の二重引用符）と行末の `,` （半角のカンマ）を消さないように注意してください。

### 3. 確かめる

1. 上の「手元のパソコンで表示する」の手順でページを開きます。
2. 画面上部のメニューに「施工事例」が増えていることを確かめます。
3. トップページを下へスクロールし、「施工事例」に写真が出ていることを確かめます。

## 文章や会社の情報を直す

| 直したい内容 | 開くファイル |
|---|---|
| 電話番号、住所、メニュー、事業の説明文 | `lib/site.ts` |
| トップページ冒頭の文章 | `components/home/Hero.tsx` |
| 代表挨拶、会社概要の表 | `pages/about.tsx` |
| 色 | `styles/globals.css` の先頭（`--blue`、`--yellow` など） |

## テスト

次の命令で、部品が正しく動くかを自動で確かめます。

```
npm test
```

公開前には、次の 2 つも実行します。どちらもエラーが出なければ公開できます。

```
npm run lint
npm run build
```

## ロゴについて

- ロゴ画像は `public/plusone_logos/` にあります。
- 今あるロゴ画像は小さい（最大で横 261 ピクセル）ため、画面上では元の大きさより小さく表示しています。
- 大きい元データが手に入ったら、同じファイル名で置き換え、`lib/site.ts` の `LOGO` にある `width` と `height` を新しい画像の大きさに書き換えます。
